# Tip Calculator

A Flutter tip calculator with bill entry, a 0–30% tip slider, people controls, and live per-person totals. Invalid or empty bill input is treated as zero.

## Run in DartPad

Open [DartPad](https://dartpad.dev/), choose Flutter, paste `lib/main.dart`, then select **Run**.

## Run locally

Install the Flutter SDK, then from this folder run:

```sh
flutter pub get
flutter run
```

## Guide test case

With a bill of `1000`, a tip of `10%`, and `4` people, the total is `1100.00` and the amount per person is `275.00`.
